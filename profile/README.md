# Initiative Online Print e.V. (IOP)

The [Initiative Online Print e.V.](https://initiative-online-print.de/en/) (short: IOP) is a worldwide unique
association of the leading companies in the online print industry in Europe to form an independent communication and
networking platform.

IOP organizes dedicated working groups that develop practical standards for the print industry.
These standards are designed to improve interoperability, simplify data exchange, and support more efficient
collaboration between printers, customers and their platforms, suppliers and software providers.

## Standards developed by IOP
- [EUDR-X](https://github.com/initiative-online-print/eudr-iop-standard-exchange-format) for exchanging information
  related to the EU Deforestation Regulation within the supply-chain
- [UCP Print](https://github.com/devucpprint) for extending the Universal Commerce Protocol (UCP)
  with additional capabilities for the print industry
